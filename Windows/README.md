# DogSC Windows版

Windows原生桌面录屏程序。使用C#、WPF、Windows Graphics Capture和Media Foundation，采集与H.264/AAC编码在本进程完成。运行时不需要浏览器、OBS或FFmpeg；FFmpeg仅用于开发阶段检查生成视频。

按用户“以现在的为基础”保留现有原生WPF/C#架构。当前使用以录屏为主，鼠标与开启的摄像头实时录入屏幕原片，录完生成MP4和可选纯音频，运镜可在录制条关闭。同一时间文件夹的素材子文件夹保留屏幕原片、声音、鼠标事件和同步数据；新录制不保存独立摄像头视频。macOS源码保留在原目录；历史项目的编辑与导入代码仍保留。

录制条“成片合成”默认开启，开启绿色、关闭灰色，只控制单击1.6倍运镜、放大等拓展效果。鼠标和开启的摄像头直接录入屏幕原片，放大时随屏幕画面一起放大，不额外重绘指针。摄像头实时镜像叠入编码器，锁和眼睛不录入；不开第二个摄像头编码器，不另存摄像头视频。关闭成片合成时，有无摄像头均直接保存原片，不再离线叠加和重编码；应用声音项目只需合并声音。开关与内部设置即时双向同步；录制中及暂停时可开关摄像头、麦克风和系统声音，并通过录制条“录制音量”调整两路0—100%的录制音量。分辨率、帧率、编码与成片模式保持本场开录规格，结束及隐藏/呼出后保留选择。默认保存仍为D:\视频，时间目录、同名MP4/M4A和素材子文件夹的规则不变。

录制时按Ctrl+Shift+S呼出录制条，点击麦克风或摄像头图标切换；点击滑杆图标展开两路音量，关闭面板不影响已设置的音量。调节只影响这份录像及其独立声音素材，不改变Windows设备音量；麦克风关闭会静音本软件录入的声音，已经建立的独立音轨会保留采集会话以维持同步。录制中不提供切换音频设备的选项；需要更换设备时先结束本场再选择。

原生指针模式不再定时轮询指针外观，移动与点击事件继续记录，运镜、帧率和视频质量不变；旧独立指针项目继续保留外观轮询。2026-10-11本机回归125项通过，2段MP4、2段M4A及麦克风验证的原片/导出片全部完整解码通过。

本机火绒6.0.12.1已由用户在“安全设置→系统防护→隐私设备保护”中，为`D:\github\dogsc\Windows\artifacts\win-x64\DogSC.Windows.exe`设置摄像头、麦克风自动允许，针对设备使用通知处理。实测该发布程序打开摄像头、使用麦克风录制并暂停/继续，335次火绒托盘窗口检查未见弹窗。该设置属于火绒本机规则，不会随DogSC安装包迁移；移到其他电脑或更换程序路径，需要在火绒对应入口重新设置。Windows免打扰不承担这两类提示的过滤。其他火绒安全提示按用户原有规则处理。

2026-10-11最新发布已验证真实摄像头+2560×1600全屏120fps、成片关闭的两组约16秒录像，保存耗时0.692/0.616秒；主MP4与屏幕原片哈希一致，摄像头不再另存。148项完整流程、6媒体7条流完整解码和后台快捷方式启动通过。详情见[摄像头原片与快速保存验证](verification/2026-10-11-camera-fastsave.md)及同名results.json；长时、4K和实际登录自启尚未实测。

## 启动与快捷键

双击`artifacts\win-x64\DogSC.Windows.exe`，或运行本目录的`run.ps1`。独立运行包需要保留同目录全部文件，不需要另装.NET运行时。首次手动启动显示引导，可打开麦克风、摄像头的Windows权限设置；完成或关闭引导后进入悬浮条，并驻留系统托盘。设置中的引导入口可再次查看。

本机桌面已创建`DogSC`快捷方式，并配置当前用户登录Windows后自动启动。自启使用`--background`参数，仅驻留托盘，按Ctrl+Shift+S呼出悬浮条；手动启动仍显示悬浮条。自启入口改为当前用户启动文件夹中的`DogSC.lnk`（运行`shell:startup`可查看），旧`Run\DogSC`在新快捷方式验证成功后移除。移动发布目录后，应重新运行`install-desktop.ps1 -ReportPath <本项目Windows/artifacts内的JSON报告路径>`；脚本保留原快捷方式与自启值备份。重复后台启动会直接退出，不弹重复运行提示。实际注销、重启后的登录触发尚未实测。

程序、窗口和托盘采用原项目图标。Windows的`Assets/DogSC.ico`由`Resources/AppIcon.icns`中现有32/64/128/256像素PNG条目原样封装，未改动图像内容。

| 操作 | 方式 |
| --- | --- |
| 显示/隐藏悬浮条 | Ctrl+Shift+S；准备、录制、暂停和保存时均可切换，保留原位置 |
| 移动整个悬浮条 | 按住空白处、DogSC名称或时钟拖动；录制和暂停时也可移动 |

关闭空闲悬浮条或设置窗口会隐藏窗口；退出程序请用托盘菜单。录制时请求退出会先询问是否停止，然后等待MP4保存完成。重复启动会提示程序已在运行。快捷键若被其他程序占用会明确报错，不会静默抢占或更换。

当前录制保存规则为下文的普通时间文件夹。红斜杠/灰色/绿色状态、后台设备检测、默认蓝牙麦克风及最高规格摄像头保持有效。发布与本机验证的时间、版本和证据见项目CHANGELOG；桌面快捷方式继续指向同一发布目录。

## 录制选项

- 模式：全屏、框选区域、指定窗口。框选采用物理像素坐标，支持高DPI缩放；选择时区外变暗、区内保持明亮，显示边线与像素尺寸。录制过程中配置锁定。
- 帧率：30、60、120fps，最高120fps。屏幕名称中的165Hz等数值是显示器信息，不是录制帧率；按最终要求不提供165fps或跟随刷新率录制。
- 录制规格：原始分辨率（默认，跟随所选显示器当前实际像素）、1080P（1920×1080）、720P（1280×720）。原始档不固定为2.5K或4K：2560×1600屏保存2560×1600，3840×2160屏保存3840×2160；不切换Windows显示模式。1080P和720P按选中尺寸编码，比例不一致时等比留边。帧率30/60/120fps独立选择。
- 非全屏模式：框选和窗口均隐藏规格选择及悬浮条中的占用列，按实际采集像素保存，不将小选区或窗口放大成1080P或2.5K。偶数尺寸800×600保存800×600；奇数边长按编码要求仅补齐1像素，641×479保存642×480。切回全屏恢复规格选择。
- 参数同步：悬浮条与“保存到/视频/项目”设置窗口双向即时同步模式、来源、帧率、规格及系统声音/麦克风；在悬浮条改为60fps后打开设置，会显示60fps。录制开始时项目和编码器使用同步后的参数；打开已保存项目时，编辑器导出默认读取该项目的录制帧率和源分辨率，支持120fps。录制期间保持配置锁定。
- 功能图标：关闭显示红色大斜杠；正在配置显示灰色；开启并配置完成显示薄荷绿色，移除右下角状态小点。点击麦克风或摄像头直接切换开关，不再弹设置窗口；耗时查询在后台进行，配置完成前不能开始录制。快速开关不会被旧查询结果重新启用。
- 默认设备：系统声音默认开启、使用Windows当前默认输出。麦克风自动模式优先活动蓝牙输入，否则使用Windows默认麦克风；开始录制前重新检查。手动指定设备仍按指定设备录制。摄像头默认选择最高支持分辨率，再选该分辨率下最高帧率；使用既有1—120fps范围，不另设摄像头编码档位或改变Windows权限。

最新悬浮条状态检查45项、拖动与参数同步66项通过。界面事件处理测量中，麦克风/摄像头点击约2ms，系统声音同步不足1ms；不是物理鼠标到屏幕的端到端延迟测量。实际HD Webcam1280×720@30、默认蓝牙麦克风与系统声音同时录屏60fps，暂停/继续/保存及完整解码通过。应用声音120fps项目内保存313帧完整解码、暂停前后440Hz测试音通过；关闭保存和重启录制均无自动外层MP4。报告见`artifacts/toolbar-device-check/20261010-172944/results.json`、`artifacts/main-flow/20261010093110-004ac0ed56dc48129fc110892009b2a2/decode-verification.json`和`artifacts/main-flow/20261010091611-78dacad917394236b00f10f661c763a8/decode-verification.json`。

本次真实窗口交互66项和中英文/模式显示检查通过；本机2560×1600屏使用原始档60fps录制后，项目、自动MP4和恢复视频均为2560×1600、60fps、155帧且完整解码。检查报告见`artifacts/toolbar-interaction-check/20261010-162829/results.json`和`artifacts/main-flow/20261010082830-ae60343480634973a724efbef85f06c5/native-resolution-verification.json`。实物4K屏、多显示器和4K120fps性能尚未验收。

- 编码质量：三种规格都使用现有高质量90，界面不再出现“清晰/标准/流畅”。分辨率与帧率直接传入原生编码器；画面复杂度、显卡及负载也会影响开销，目标帧率不保证每帧都是不同画面。
- 声音：系统声音、麦克风可分别开关；同时勾选即混音，两者关闭即静音。设置窗口可以选择设备；独立WASAPI音轨保留供编辑使用。窗口模式可显式选取应用进程树声音。
- 编码：H.264和HEVC按本机Media Foundation编码/解码能力检测；录制后的摄像头/运镜合成保留录制所选编码，HEVC导出失败会明确报错并保留原片，不自动改成H.264。ProRes未提供编码插件，明确显示不可用。录制尺寸菜单按用户后续要求采用上面的三种标准规格。
- 摄像头：关闭为默认值；开启后使用设备实际格式，实时镜像录入屏幕原片，不保存独立摄像头视频。摄像头规格不改变录屏帧率与尺寸；真人口型同步和长期稳定性仍待验收。
- 免打扰：可选，默认关闭。勾选后临时通过Windows通知设置启用，结束时恢复原状态；也可使用“免打扰设置”按钮自行设置。强制结束进程后可能需要手动恢复。

悬浮条按原布局等比缩小至80%，摄像头保持560×380物理像素。未录制时，设置、悬浮条、框选界面和摄像头均允许截图；正常录制时用Windows窗口排除接口保持成片纯净。指定窗口模式采集目标窗口；全屏和区域录制不能通用地排除火绒等其他进程的独立弹窗。这类提示仍需在相应软件中关闭或使用指定窗口录制。

录制条按原版白色圆角、薄荷绿选中态、图标式来源和圆形声音按钮重绘。录制前将鼠标停在按钮、来源、帧率或录制规格上约0.45秒显示说明；尚未启用的暂停按钮也提供快捷键说明。较长提示自动换行。开始采集前关闭已打开的提示与下拉菜单，录制、暂停、收尾期间禁止弹出提示，保存结束后恢复。

区域录制期间显示细边框：绿色表示录制、黄色表示暂停、橙色表示启动或收尾。边框不拦截鼠标操作，并排除在录制画面之外。真正开始录制后播放一次短双音，暂停后继续不重复响；提示音受Windows输出音量影响，录制系统声音或麦克风时也可能被录入。

帧率和分辨率设置直接传入录制编码器，不在后台统一按最高规格编码。此前原生2560×1600测试中，30/60/120fps的20秒样片分别输出600/1200/2400帧；历史编码质量65/80/90的同画面码率约为13.03/17.23/20.88Mbps，当前界面已改成明确规格并固定质量90。码率随画面变化，CPU/GPU占用也不会与档位数字严格成比例。此前120fps动态全屏受控测试中，录前和录中的画面渲染间隔P95/P99一致，私有内存峰值约2.06GiB。按用户要求保留质量，不因该内存峰值自动降档。历史测试条件及边界见[性能验证说明](artifacts/profile_output/性能验证说明.md)。

## 保存、播放与导出

设置窗口或首次引导选择的界面语言会保存到当前用户的`%LOCALAPPDATA%\DogSC\interface-settings.json`，下次启动恢复。保存失败会保留旧设置并提示路径；损坏的设置文件不会被启动过程自动覆盖。语言切换同步录制条、设置窗口和编辑器，底层项目参数值保持不变。

设置中的“导出MP4”对普通Windows录像继续直接复制带声音的原片；对应用声音项目以及没有`capture-options.json`的旧版/Mac导入项目，会合并已有独立音轨，保留压缩视频样本。2026-10-11新增受控Mac音轨、真实16kHz蓝牙输入和界面契约回归，证据及边界见[修复报告](verification/2026-10-11-contracts.md)。

默认保存目录为`D:\视频`，设置窗口与悬浮条使用同一位置。开始录制时若目录不存在，会自动创建后再保存；可在设置中另选目录。

录制停止后保存普通时间文件夹，例如`2026-10-10 18-30-12`；其中有`2026-10-10 18-30-12.mp4`、可选`2026-10-10 18-30-12.m4a`及`素材.dogscproject`子文件夹。时间取本次真正开始采集的本地时间，精确到秒，不带“录制”、随机串或项目后缀。没有录制声音时仅保存MP4。纯音频直接复制最终视频中的AAC压缩样本，不重复编码。悬浮条和设置窗口使用同一规则。

成片在停止录制后按原录制帧率、分辨率应用所选运镜，再抽取纯音频；关闭成片合成直接保存原片。指针和开启的摄像头已在屏幕原片中，不再额外重绘或离线叠入摄像头。独立WAV、鼠标事件、同步数据及运镜参数保留在`素材.dogscproject`中；不生成`camera.mp4`、`camera.mov`或`camera-sync.json`。新录制的摄像头已嵌入屏幕，无法在编辑器中单独移位，历史项目里的独立摄像头仍兼容。保存失败时保留已有素材并报告路径；同秒目录冲突时拒绝覆盖，保留原文件。完成后悬浮条时钟归零，仅保留录制选项，“继续”只在暂停状态出现。

选择摄像头后，收到第一帧画面才显示560×380物理像素的置顶预览；配置等待期间不弹出黑色空窗。按住画面拖动；左上角开锁/闭锁图标直接浮在画面上，没有底块，开锁只画锁环左半边，闭锁画完整锁环并亮绿色，点击或右键切换固定。右上角眼睛亮起/睁开表示显示预览，闭眼表示隐藏；隐藏时仅在原右上角保留透明眼睛按钮，点击恢复原位置。未录制时收起悬浮条会真正关闭摄像头窗口并释放设备，再次呼出按已选设备恢复；录制中收起或呼出悬浮条不改变摄像头，开始录制只自动收起悬浮条。录制中手动点眼睛只隐藏桌面预览，摄像头画面仍持续录入；停止录制立即关闭窗口和设备，保存完成后不自动重开，设备选择保留供下次使用。窗口位置、锁定与眼睛选择在重新创建时保留，并限制在显示器工作区内。预览和视频中的摄像头画面均水平镜像，屏幕内容不镜像；锁和眼睛排除采集。预览和实时录入复用同一个无编码摄像头源，桌面预览最多30fps；录入更新率不超过设备实际帧率及录屏帧率的较小值。摄像头30fps不会把屏幕降为30fps；最终MP4使用屏幕所选30/60/120fps、输出尺寸和质量90。

“打开项目”可以选择录制的时间文件夹或里面的`素材.dogscproject`子文件夹；macOS项目通过独立导入入口创建Windows副本。普通Windows原片导出复制MP4、不重复编码；应用声音项目和没有采集配置的旧版/Mac导入项目将独立音轨合并到原视频，视频样本保持压缩格式。120fps分片样例已修正原生读取器时间戳，并通过2415帧/20.125秒与原视频压缩码流哈希相同的对照。支持取消，覆盖文件前确认。自动保存不覆盖已有文件。失败时保留已写入的项目和素材，并报告路径；未完成的MP4不一定可以播放。原项目媒体有效但另存MP4失败时，可以从项目中播放或重新导出。

“播放”使用本机默认视频播放器打开刚保存的视频。“打开文件夹”打开这次的时间目录。完成录制后可以用“编辑视频”调整保留的运镜、鼠标、摄像头及声音，再从编辑器导出成片；旧录像中已删除的轨道无法恢复。


## 自动运镜与PixPin截图

2026-10-11修复：摄像头开关的鼠标与无障碍操作均按勾选状态启用/关闭，设备状态回写不会触发重复配置。锁和眼睛的悬停提示在录制时关闭并禁用，暂停或空闲时恢复。PixPin在回放截图快捷键前注册当前进程窗口事件监视，结合关闭轮询识别短暂显示的截图界面；未确认截图出现时仍保持暂停，不盲目继续。验证及未覆盖场景见[修复报告](artifacts/bugfix-20261011/修复与验证报告.md)。

普通录制直接录入电脑的系统指针：成片不额外重绘指针或轨迹线，指针随屏幕画面放大。位置事件留在素材中供自动运镜判断；旧项目的独立指针仍可兼容回放。运镜沿用本地原版源码：一次左键或右键点击触发1.6倍缩放，进入/退出约0.7秒，相隔不超过1.4秒且位置相近的操作合并；连续操作时镜头跟随，平稳区内不过度追逐。1.6倍显示约原画面62.5%的宽和高，最终MP4尺寸不变，新录制中已嵌入的摄像头随屏幕画面一起变化。运镜在录完生成成片时应用，录制采集仍按选择的30/60/120fps工作，不另开120fps视频录制。历史独立轨道仍能在编辑器中分别调整，新录制不再保留独立摄像头轨道。

本机PixPin当前截图快捷键Print和Ctrl+Alt+A已接入保护：录制中按键后先暂停屏幕编码和声音轨道，摄像头实时预览继续，临时允许截图，确认暂停后才触发PixPin；截图界面结束或Esc取消后自动继续。截图联动不主动显示或隐藏录制条、摄像头：原来隐藏就保持隐藏，原来显示就保持显示；需要截录制条时先按Ctrl+Shift+S呼出。截图操作时间不计入视频。原本手动暂停时截图不会自动恢复；截图期间手动改变暂停状态、停止录制或退出会取消自动继续。

保护仅在PixPin运行且当前配置对应这两个动作时生效；修改为其它快捷键、从托盘/脚本调用截图时，须先手动暂停。全屏PixPin贴图也会保守阻止继续，收起全屏贴图后才能恢复。未确认截图页出现、暂停未确认或键回放失败时保持暂停并显示错误，可在关闭截图界面后按Ctrl+Shift+空格继续。暂停确认后再放开截图，避免把录制条、锁/眼或PixPin截图界面写入成片。

## 开发与验证

在本目录运行：

```powershell
.\build.ps1
.\run.ps1
```

构建脚本先运行Core与Windows录制/故障恢复自测，再生成自带运行时的win-x64目录。工具链使用项目内`.tools\dotnet\dotnet.exe`，SDK版本10.0.401；没有修改系统PATH。换机器构建时需将微软相同版本SDK解压至该目录。NuGet仅使用官方源，项目提供依赖锁文件；Windows移植目录目前尚未提交Git。

2026-10-11故障恢复修复的范围、复跑命令和验证边界见[报告](verification/2026-10-11-bugfixes.md)。Windows层已有独立自测源码，包括原生收尾故障注入、文件保留、音频/事件降级、导出闸门和界面恢复；真实设备检查需显式运行自测的`--main-live`、`--audio-live`及`--media`入口。小型汇总证据放在`verification/`，本机完整日志仍保留在`artifacts/`。

添加录制标记只在正在录制时有效；暂停、准备和收尾时，设置按钮与托盘/热键入口一致禁用。排队中的旧操作也会提示暂停时不能添加，不再无反馈地忽略。

录制库固定为ScreenRecorderLib6.6.0。7.0.1在本机出现丢帧间隙及录制收尾错误；对照验证表明6.6.0恢复连续输出，30/60/120fps均已验证，因此固定此版本。已安装的VC++运行库为14.50；其他机器还需具备相应x64 VC++运行库。
