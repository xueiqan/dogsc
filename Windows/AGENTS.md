# DogSC Windows协作规则

- 本目录是现有C#/WPF原生Windows录屏实现。修改前读取本目录`README.md`相关部分和上级`CHANGELOG.md`的最新记录，保留仓库原macOS部分与当前Windows入口，不改造成另一套技术方案。
- 摄像头与鼠标按当前约定实时进入屏幕原片；关闭成片合成时也保留已录入内容。新录制不另存独立摄像头视频，历史项目已有素材继续兼容，保存失败时保留可恢复的原始素材。
- 区分摄像头预览隐藏、窗口关闭与停止采集：录制中收起录制条不关闭摄像头，手动隐藏桌面预览仍持续录入；停止录制时关闭摄像头窗口和设备。未录制时的显示、关闭与恢复沿用现有行为，避免开始录制反而关闭已选摄像头。
- 录制条中的摄像头、麦克风、系统声音开关和两路录制音量要落实到实际采集，并与设置即时同步；本软件录制音量不替用户修改系统设备音量。允许录制中调整的项目与本场固定的分辨率、帧率、编码等规格分别处理。
- 成片合成开启显示绿色、关闭显示灰色；后台自启只驻留托盘。沿用用户最新确认的录制、保存、呼出和截图分工，不把旧剪辑方案恢复为当前默认流程。
- 火绒相关处理只针对本程序摄像头、麦克风的设备使用通知及已授权规则，保留其他防护；换程序路径或环境后重新核实，不能宣称本机设置会随安装包迁移。
- 构建和验证按本目录`README.md`的“开发与验证”使用现有入口与项目工具链；按改动选择软件检查或实际录制检查，编译结果不代替摄像头、声音、保存与最终视频的实际效果。
- 改动沿用上级`CHANGELOG.md`；只记录本次实际变更和验证范围，保留已有录像、用户设置及无关源码。
