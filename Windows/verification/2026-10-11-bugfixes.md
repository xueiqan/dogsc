## 复跑

在`D:\github\dogsc\Windows`使用项目SDK，环境按`build.ps1`设置：

```powershell
$env:DOTNET_ROOT = "$PWD\.tools\dotnet"
$env:DOTNET_CLI_HOME = "$PWD\.tools\cli"
$env:NUGET_PACKAGES = "$PWD\.tools\nuget"
& .\.tools\dotnet\dotnet.exe run --project DogSC.Core.SelfTest -c Release
& .\.tools\dotnet\dotnet.exe run --project DogSC.Windows.SelfTest -c Release
```

`build.ps1`现在先运行Core和Windows自测，再发布。真实设备与UI入口见自测`Program.cs`。真实测试输出必须是新目录；测试媒体只在项目artifacts下生成。不要把编译、人工文件故障注入当成设备拔插或长期稳定性证明。
